# Project Memory

## Core
- PadhLo With Us is a learning platform for Indian CS/IT students and early-career developers.
- Use a light, clean interface with generous whitespace, subtle shadows, deep indigo primary, amber highlights, slate neutrals, green completion, and red errors.
- Use Inter for interface text and JetBrains Mono for code; keep the tone friendly, clear, and encouraging.
- Never invent statistics, user counts, testimonials, or company logos.
