## Checkpoint
You're ready to start machine learning when you can do these without looking anything up:

- Write functions and loops in Python, and use lists and dicts comfortably
- Create a virtual environment and install packages
- Load a CSV with Pandas, clean it, and summarise it with `groupby`
- Use NumPy arrays and read shapes like `(100, 3)`
- Plot a line chart and a histogram
- Explain mean, standard deviation and a dot product in your own words

## Next step
If most of these feel solid, start the **ML Engineer** roadmap. If two or more feel shaky, revisit those topics first. It's faster than getting stuck later.
