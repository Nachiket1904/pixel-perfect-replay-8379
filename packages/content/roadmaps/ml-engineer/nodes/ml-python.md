## Why this matters
Most ML work is data work. You'll spend more time in NumPy and Pandas than in model code, so fluency here pays off on every project.

## What to learn
- NumPy: vectorised operations, broadcasting, boolean masks
- Pandas: `read_csv`, `loc`/`iloc`, `groupby`, `merge`, handling missing values
- Notebooks for exploration, `.py` files for anything you reuse

## Try this
Load any CSV, then compute the same column average three ways: a Python loop, NumPy, and Pandas. Time each with `%timeit` in Jupyter.
