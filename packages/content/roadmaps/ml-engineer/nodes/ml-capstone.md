## Checkpoint
Ship one end-to-end project that shows the whole workflow:

1. A real problem and a public dataset
2. Data cleaning and a written note on what you found
3. A baseline, then at least two models compared with the right metric
4. The best model served behind a FastAPI endpoint
5. A README with the problem, results, how to run it, and what you'd do next

## Done when
A stranger can clone your repo, run it with a few commands, and get a prediction. Put the link on your resume and LinkedIn.
